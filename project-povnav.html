Visual navigation in image space

Pareto-optimal decisions that connect visual perception directly to robot action.

Paper ↗Watch video ↗

Overview

This work investigates how a robot can choose useful actions directly in image space. Navigable regions provide a compact representation for balancing progress and exploration without maintaining a global geometric map. The framework connects semantic perception to an interpretable navigation policy.

Highlights

  • A modular image-space navigation framework connecting segmentation, decision-making, and visual control.
  • Pareto-optimal decisions that balance navigation objectives.
  • Experiments across simulated and physical robotic platforms, including field navigation.
