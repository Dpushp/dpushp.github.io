Context-generative default policies

Using predicted context to guide bounded-rational decisions in unknown environments.

Paper ↗Watch video ↗

Overview

A default policy provides a reference for decisions under bounded computation. This work makes that reference responsive to the environment by predicting unseen map regions and using them to generate candidate behavior. Bounded adaptation around that policy helps the robot respond to inaccurate predictions.

Highlights

  • A context-generative default policy informed by observed and predicted map regions.
  • Diffusion-based map prediction combined with sampling-based planning.
  • Evaluation in simulation and physical Crazyflie drone experiments.
