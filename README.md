# Durgakant Pushp — academic website

A clean, responsive, multipage academic website prepared for https://dpushp.github.io/.

**Start with `UPDATE_GUIDE.md`** for upload instructions and content editing.

- Ready-to-upload HTML: no build or dependencies required for hosting.
- Optional generator: `python3 build.py` (Python standard library only).
- Edit research video URLs directly in `videos.js`; no build required.
- Replace the photo at `assets/images/profile.png`.
- Replace the CV at `assets/Durgakant_Pushp_CV.pdf`.
- Content source: `data/`; design: `style.css`; interactions: `script.js`.
- Future lab branding and People page are enabled via `data/profile.json` and a local rebuild.

Upload this folder's contents to your existing repository root, including the assets folder. Do not upload the ZIP file itself. Keep Pages set to deploy `main` / root.
