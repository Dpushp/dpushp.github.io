Coordination of bounded-rational drones

Informed prior policies for collective decisions with limited computation.

Paper ↗Watch video ↗

Overview

This work studies how useful prior behavior can improve multi-robot coordination when agents cannot evaluate every possible choice. An informed prior policy supplies navigation heuristics, and a bounded-rational game-theoretic framework supports adaptation and coordinated motion.

Highlights

  • A learned, goal-directed prior policy for bounded-rational agents.
  • Integration with a game-theoretic multi-agent planning framework.
  • Simulation and physical experiments with multiple drones.
